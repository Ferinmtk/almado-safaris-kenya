WHAT'S HERE
- index.html  → your complete homepage (open it in any browser to preview)

BEFORE YOU GO LIVE — 4 edits (open index.html in any text editor and search for):
1. 2547XXXXXXXX        → your WhatsApp number, no + or spaces (e.g. 254712345678)
2. REPLACE_            → your real phone and email
3. PHOTO:              → swap in your own images (hero, destinations, fleet)
4. YOUR_FORM_ID        → your Formspree form ID (see below)

SETTING UP THE CONTACT FORM (Formspree)
1. Go to formspree.io and create a free account.
2. Create a new form — it gives you an ID like "xnqkmabc".
3. In index.html find:  action="https://formspree.io/f/YOUR_FORM_ID"
   Replace YOUR_FORM_ID with your ID.
4. Done — inquiries now land in your email inbox.

HOSTING (publishing the site)
This is a static site, so hosting is cheap/free. Easy options:
- Netlify (netlify.com) — drag this folder in, done.
- Cloudflare Pages or GitHub Pages — free.
- Any cPanel host — upload index.html to public_html.
Then point your domain AlmadoSafarisKenya.com to it.
